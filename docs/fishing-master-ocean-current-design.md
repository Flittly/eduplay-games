# 《捕鱼达人 · 洋流版》完整设计方案

> **素材基准**：人教版图 4-24《世界表层洋流的分布（北半球冬季）》
> 图中约定：**红色箭头 = 暖流**（由低纬流向高纬，增温增湿）；**蓝色箭头 = 寒流**（由高纬流向低纬，降温减湿）

---

## ⛔ 第零条铁律：洋流先分类，再按教学重要性分层

> **本游戏是要进课堂做教学任务的，所以洋流清单不能"一锅端"。**
> 正确的做法不是"教材里没有的一律不写"，而是：
>
> **① 先按教材体系分类** → **② 按教学重要性分三层**
> → **③ 重点层详细讲、拓展层简要提、了解层只作例证**
>
> 学生的时间是有限的。**分层的目的，是让复习火力集中在考点上**，
> 而不是把图 4-24 上的所有箭头都当成同等重要的东西去背。

### 0.1 三层分级总览（本方案的洋流顶层结构）

| 层级 | 纳入标准 | 数量 | 教学要求 | 游戏中 |
|---|---|---|---|---|
| **① 重点层** | 教材正文/图中出现、属熟记环流体系 | **16 条** + 季风洋流（高中） | **能认名称、能判性质、能判方向**，详细展开成因 | ✅ 完整两层判定 + 详细解释卡 |
| **② 拓展层** | 教材体系外、但真实存在且图上标了箭头 | **约 6 条** | **知道存在即可**，不要求熟记 | 🔸 可捕捞，**只认名称不判方向**；标注"拓展·课标不考" |
| **③ 了解层** | 教材"影响"部分点名的非环流用法 | **3 条**（影响侧面） | **只作例证理解**，不作判定 | 📖 只出现在解释卡文字里 |

> ⚠️ **核心纪律**：分层的价值**全在呈现上**。
> 如果三层在界面上长得一样，这个分层就白做了——学生仍然分不清哪些该背。
> 详见 0.4「分层如何落到界面上」。

### 0.2 ① 重点层：教材熟记清单（唯一真相源）

教材对洋流的要求是**按顺序熟记四个闭合环流 + 一条环球漂流**：

| 环流 | 顺序（按流向） | 性质 |
|---|---|---|
| **北太平洋**（顺时针） | 北赤道暖流 → 日本暖流 → 北太平洋暖流 → 加利福尼亚寒流 | 暖暖暖寒 |
| **南太平洋**（逆时针） | 南赤道暖流 → 东澳大利亚暖流 → 西风漂流 → 秘鲁寒流 | 暖暖寒寒 |
| **北大西洋**（顺时针） | 北赤道暖流 → 墨西哥湾暖流 → 北大西洋暖流 → 加那利寒流 | 暖暖暖寒 |
| **南大西洋**（逆时针） | 南赤道暖流 → 巴西暖流 → 西风漂流 → 本格拉寒流 | 暖暖寒寒 |
| **南印度洋**（逆时针） | 南赤道暖流 → 厄加勒斯暖流 → 西风漂流 → 西澳大利亚寒流 | 暖暖寒寒 |
| **北印度洋**（季风洋流） | 冬季自东向西·逆时针 / 夏季自西向东·顺时针 | 随季节反向 |

**这份清单的闭合性本身就是最好的教学点**——教材总纲说"全球海洋表层洋流构成了分别以
副热带和副极地为中心的大洋环流"，上面这四条环流正好就是它的实例。
**游戏应当把"环流是闭合的"做成可感知的机制**（见 0.5）。

### 0.3 ② 拓展层：体系外但真实存在的洋流（简要提及）

图 4-24 上标注的箭头**多于**教材要求学生熟记的清单。这些洋流**不是错误**，
也不是"不许出现"——它们是**真实存在的地理实体**，只是不在课标要求里。

| 洋流 | 位置 | 处理 |
|---|---|---|
| 阿拉斯加暖流 | 北太平洋东岸 | 🔸 简要提及 |
| 赤道逆流 | 赤道无风带 | 🔸 简要提及 |
| 东格陵兰寒流 | 北大西洋北部 | 🔸 简要提及 |
| 索马里寒流 | 北印度洋西岸（夏季） | 🔸 简要提及 |
| 莫桑比克暖流 | 非洲东南岸 | 🔸 简要提及 |
| 北冰洋南下冷水 | 北大西洋北部 | 🔸 简要提及（教材在"北海渔场"成因里点到过） |

> **为什么保留而不是删除**：学生**知道一条真实洋流存在**，这件事本身不产生错误知识；
> 会出问题的是**把它当成考点去背**。而只要在**呈现上做区分**（虚线 + "拓展"角标 +
> "课标不考"说明），学生就自动明白哪些要背、哪些只是看看。
> **这个"分辨轻重"的能力，本身就是信息素养训练。**
>
> 老师也因此敢用：**重点层完整覆盖考纲，拓展层明确标注，不影响教学进度。**

### 0.4 分层如何落到界面上（关键，别做表面功夫）

| 层级 | 地图上的画法 | 判定深度 | 解释卡 |
|---|---|---|---|
| **① 重点** | **实心高亮箭头**，颜色饱和 | 认名称 + 判方向（两问） | 详细展开成因（上升流/交汇/大陆架） |
| **② 拓展** | **虚线描边 + "拓展"角标**（灰蓝） | **只认名称**，不问方向 | 一句话 + "⚠️ 拓展内容，课标未要求熟记" |
| **③ 了解** | 不在地图上单独标 | 不作判定 | 作为"影响"例证写进重点层洋流的卡里 |

**三条呈现纪律**：
1. **一眼可辨**——三层必须颜色/线型/角标都不同，不能只是文字说明；
2. **拓展层不计入通关**——学生漏掉任何一条拓展洋流，都不影响"集齐四大环流"的通关判定；
3. **拓展层可整体延后**——若排期紧张，P0 只做重点层 16 条，拓展层放 v2。
   **它是加分项，不是必需项。**

### 0.5 用"教材原生的结构"做玩法（把闭合成做机制）

既然四个环流是闭合的，就把它变成玩家的**成就感来源**：


```
【环流图鉴】北太平洋环流   ✓ 已集齐 4/4

  北赤道暖流 ──▶ 日本暖流 ──▶ 北太平洋暖流
       ▲                              │
       └──────── 加利福尼亚寒流 ◀─────┘
                    ↑ 你已在此下网 3 次

  ★ 集齐一个完整环流：额外奖励 +100
  ★ 四大环流全部集齐：解锁"全球洋流总图"（可在图鉴里反复查看）
```

**这个设计的教学价值极高**：学生在凑环流的过程中，**自然记住的是一条链的完整顺序**，
而不是零散的四个名字。而且它直接复刻了教材"按顺序熟记"的要求——
**游戏里的收集顺序 = 课本上的背诵顺序。**

### 0.6 数据层：三层分级写成代码（构建期强制分层）

分层不能只写在文档里——**必须落到数据文件的类型上**，否则下次加洋流时没人记得分层。
照本仓库 `scripts/` 下数据驱动脚本的一贯做法，把三层做成**联合类型 + 构建期校验**：

```ts
/**
 * 洋流教学层级 —— 唯一真相源。
 * 加新洋流时必须显式声明层级，编译器会强制你回答"这条是重点还是拓展"。
 */
export type CurrentTier =
  | "core"      // ① 重点：教材熟记清单，必须能认能判，详细讲
  | "extension" // ② 拓展：体系外真实洋流，简要提及，只认名称
  | "reference"; // ③ 了解：仅作"影响"例证，不作捕捞区

/** ① 重点层：四个闭合环流的 16 条（西风漂流重复出现但只是一个 id）+ 季风洋流 */
export const CORE_CURRENTS = [
  // 北太平洋环流
  "北赤道暖流", "日本暖流", "北太平洋暖流", "加利福尼亚寒流",
  // 南太平洋环流
  "南赤道暖流", "东澳大利亚暖流", "西风漂流", "秘鲁寒流",
  // 北大西洋环流
  "墨西哥湾暖流", "北大西洋暖流", "加那利寒流",
  // 南大西洋环流
  "巴西暖流", "本格拉寒流",
  // 南印度洋环流
  "厄加勒斯暖流", "西澳大利亚寒流",
  // 北印度洋（高中版启用）
  "北印度洋季风洋流",
  // 教材"渔场成因"点名，作交汇搭档
  "千岛寒流", "拉布拉多寒流",
] as const;

/** ② 拓展层：教材体系外、但图 4-24 上有标注的真实洋流 */
export const EXTENSION_CURRENTS = [
  "阿拉斯加暖流", "赤道逆流", "东格陵兰寒流",
  "索马里寒流", "莫桑比克暖流", "北冰洋南下冷水",
] as const;

/** ③ 了解层：教材"影响"部分点名过的用法（本身多已属重点层） */
export const REFERENCE_CURRENTS = [
  "北大西洋暖流", "秘鲁寒流", "西澳大利亚寒流",
] as const;

/**
 * 构建期校验 —— 三条规则，任一违反就 exit(1)。
 * ⚠️ 必须在**构建时**跑，运行时才发现就晚了。
 */
export function assertTiering(entries: { name: string; tier: CurrentTier }[]): void {
  const errs: string[] = [];

  for (const e of entries) {
    const declared: readonly string[] =
      e.tier === "core" ? CORE_CURRENTS
      : e.tier === "extension" ? EXTENSION_CURRENTS
      : REFERENCE_CURRENTS;

    // 规则 1：名称必须真的属于所声明的层级（防止"降级逃避判定"或"升级冒充考点"）
    if (!declared.includes(e.name)) {
      errs.push(`「${e.name}」声明的层级 ${e.tier} 与名单不符`);
    }
    // 规则 2：同一名称不得跨层重复——分层必须互斥
    const hit = [CORE_CURRENTS, EXTENSION_CURRENTS, REFERENCE_CURRENTS]
      .filter((list) => list.includes(e.name as never)).length;
    if (hit > 1) errs.push(`「${e.name}」同时出现在多个层级，分层必须互斥`);

    // 规则 3：拓展层只认名称，不许有方向判定数据
    if (e.tier === "extension" && "direction" in e) {
      errs.push(`「${e.name}」是拓展层，不应带风流向判定（拓展层只认名称）`);
    }
  }

  if (errs.length) {
    throw new Error("洋流分层校验失败：\n  - " + errs.join("\n  - "));
  }
}
```

> **为什么用联合类型而不是一个白名单数组**：
> 白名单只能告诉你"这个名字合不合法"，**管不住"它该有多重要"**。
> 用 `CurrentTier` 联合类型，新增洋流时**不写层级就编译不过**——
> 分层从"文档约定"变成"类型约束"，这才守得住。

## 一、先明确这个游戏"在教什么"（设计前提）

洋流这一节，学生最容易混的其实就三件事：

| 难点 | 表现 | 本游戏怎么解决 |
|---|---|---|
| **认名称** | 知道"秘鲁寒流"这个名字，但在地图上指不出来 | 鱼群只出现在特定洋流区，**想知道能钓什么鱼，必须先认出这条流** |
| **判性质** | 分不清暖流寒流 | 图中用**红/蓝**区别，游戏里鱼的品质与颜色跟着性质走 |
| **辨方向** | 记不住"由低纬流向高纬" | 捕捞的第二步就必须**指出箭头方向**——方向答错，鱼跑了 |

**核心设计主张**：

> **把"洋流"从被考的知识点，变成捕鱼的必要工具。**
> 玩家为了钓到好鱼，**主动去认洋流、判方向**——这正是最有效的学习动机结构。

## 二、核心玩法与目标

### 2.1 一句话玩法

玩家驾船在**大洋图**上航行，选择一处海域下网。下网后进入两步判定——
**① 这条洋流叫什么？② 它往哪个方向流？**——两步全对才能起网，答错鱼群散走。
洋流的性质（寒流/暖流）与位置，决定这一网能捕到的**鱼的种类、数量与品质**。

### 2.2 游戏目标

| 层级 | 目标 |
|---|---|
| **单局目标** | 在规定下网次数内（如 12 网）捕到尽量高的**渔获总价值** |
| **教学目标** | 集齐**图鉴**：图中全部主要洋流 + 对应鱼种 |
| **终极目标** | 捕到"四大渔场"专属的**旗舰鱼种**（如秘鲁渔场的鳀鱼） |

### 2.3 单局流程

```
┌─ 出航 ────────────────────────────────┐
│  世界洋流图上，玩家选一处海域下网      │
│  （图上只显示洋流箭头与颜色，不显示名字）│
│  ① 重点层：实心高亮箭头                │
│  ② 拓展层：虚线 + "拓展"角标            │
└───────────────────────────────────────┘
              ↓
┌─ 第一问：这是什么洋流？ ──────────────┐
│  「你在这片海域下网。这里的洋流是——」   │
│   [ 秘鲁寒流 ] [ 巴西暖流 ]            │
│   [ 南赤道暖流 ] [ 西风漂流 ]          │
│  （选项从图中真实洋流池中抽，含干扰项）  │
└───────────────────────────────────────┘
    答对 ↓                    ↓ 答错
┌─ 第二问：它往哪边流？ ──┐   ┌─ 鱼群散走 ──┐
│  在图上点出箭头方向      │   │ 本网作废     │
│  或选：向高纬 / 向低纬   │   │ 消耗 1 次下网│
│  ⚠ 拓展层跳过此问直接起网 │   └─────────────┘
└─────────────────────────┘          ↓
    判对 ↓        判错 ↓              │
┌─ 起网 ─────┐  ┌─ 鱼跑了 ─┐         │
│ 按洋流品质  │  │ 空网      │         │
│ 结算渔获    │  │ 不扣次数  │         │
└────────────┘  └──────────┘         │
     ↓                                ↓
┌─ 渔获结算 + 图鉴解锁 ─────────────────┐
│  鳀鱼 ×12（秘鲁寒流 · 顶级渔场）      │
│  单价 8 · 小计 96                     │
│  ① 重点：解释卡详讲上升流成因         │
│  ② 拓展：一句话 + "课标未要求熟记"     │
└───────────────────────────────────────┘
```

> **分层在流程上的落点**：**拓展层只走第一问**（认得出名字就起网），
> **重点层走全两问**。这是分层最实在的体现——
> 拓展层的学生体验是"我认识这条流，不错"，而不是"又一道要背的题"。

## 三、洋流与鱼群的对应关系（本方案核心）

### 3.1 判定鱼群品质的三条真实地理依据

高品质鱼群（大渔场）的成因，教材上有明确的三条，本游戏**严格按这三条给品质定级**：

| 依据 | 说明 | 游戏中的体现 |
|---|---|---|
| **① 上升补偿流** | 离岸风把表层海水吹走，深层冷水上涌，带来大量营养盐 | **最高品质**。秘鲁寒流是典型——**这是全游戏品质天花板** |
| **② 寒暖流交汇** | 冷暖水相遇，海水受扰动上泛，饵料丰富 | **高品质**。北海道渔场（日本暖流×千岛寒流）、纽芬兰渔场（墨西哥湾暖流×拉布拉多寒流）、北海渔场（北大西洋暖流×北冰洋南下冷水） |
| **③ 大陆架宽广** | 光照充足、饵料丰富 | **中高品质**。如北海渔场同时具备②③ |

> **凡是不具备上述条件的洋流区，品质一律降到"普通"。**
> 这样"哪里鱼多鱼好"就不是我编的，而是**地理规律推出来的**——学生玩久了会自己总结出规律。

### 3.2 洋流的三层重要性分级（教学维度）

> **先分类，再分层。** 洋流清单不是"教材有 / 没有"的二元判断，而是**教学重要性**的分层：
> 教材出现的要求**能认能判**（重点）；教材没出现的**知道存在即可**（拓展）。
> 学生的时间有限，**必须把复习火力集中在重点层**。

| 层级 | 纳入标准 | 数量 | 游戏中的处理 |
|---|---|---|---|
| **① 重点层** | 教材正文/图中出现、属于熟记环流体系 | **16 条**（详见 3.3） | ✅ **可作独立捕捞区**；认名称 + 判方向两问完整考；解释卡详细展开成因 |
| **② 拓展层** | 教材体系外但真实存在、图上标了箭头 | **约 6 条**（详见 3.4） | 🔸 **可作独立捕捞区，但只认名称、不判方向**；解释卡一句话点明"这是拓展内容，课标不考" |
| **③ 了解层** | 教材正文点名的非环流洋流 | **3 条**（详见 3.5） | 📖 **不作捕捞区**，只在解释卡/图鉴里作为"影响"例证出现 |

**为什么这样分层而不是一刀切删除**：
- 学生**认识一条真实存在的洋流**这件事本身不产生错误知识——错的是"把它当成考点去背"。
- 但只要在**呈现上做区分**（不同颜色标记、不同判定深度、"课标不考"角标），
  学生就自动明白了哪些要背、哪些只是看看。**这本身就是一种信息素养训练。**
- 老师也敢用了：重点层完整覆盖考纲，拓展层明确标注，不影响教学进度。

> ⚠️ **呈现纪律（关键）**：三层的**视觉区分必须一眼可辨**——
> 重点层用实心高亮、拓展层用虚线描边 + "拓展"角标、了解层只出现在卡片文字里。
> **如果三层在界面上长得一样，这个分层就白做了。**

## 四、答题判定流程（交互细节）

### 4.1 第一问：认洋流名称

**出题逻辑**：

```
① 从玩家下网的位置，取该位置**真实所在的洋流**作为正确答案
② 干扰项从"图中真实存在的其他洋流"中抽取，并遵守两条规则：
   · 至少一个同半球（避免学生靠南北半球蒙）
   · 至少一个性质相同（暖流题里混一个暖流，防止"只记颜色"就能答对）
③ 选项 4 个，正确项位置随机
```

**参考实现**（纯逻辑，可节点单测，照 `china-relief/src/game.ts` 的做法）：

```ts
export interface Current {
  id: string;
  name: string;          // 秘鲁寒流
  kind: "warm" | "cold"; // 红 / 蓝
  hemisphere: "N" | "S";
  ocean: string;
  direction: number;     // 流向角度（用于第二问的箭头判定）
  quality: 5 | 4 | 3 | 2 | 1;
  fish: string[];
  reason: string;        // 地理成因，弹出卡用
}

/** 生成干扰项：同半球 + 同性质各至少一个 */
export function buildOptions(target: Current, pool: Current[]): Current[] {
  const sameHemi = pool.filter(c => c.id !== target.id && c.hemisphere === target.hemisphere);
  const sameKind = pool.filter(c => c.id !== target.id && c.kind === target.kind);
  const picked = new Set<string>();
  const out: Current[] = [target];
  // 先保底各塞一个
  for (const cand of [pickRandom(sameHemi), pickRandom(sameKind)]) {
    if (cand && !picked.has(cand.id)) { out.push(cand); picked.add(cand.id); }
  }
  // 不足 4 个就随机补
  while (out.length < 4) {
    const c = pickRandom(pool.filter(x => !out.some(o => o.id === x.id)));
    if (!c) break;
    out.push(c);
  }
  return shuffle(out);
}
```

### 4.2 第二问：判流向

**这是本作的差异化设计——第二问不能省。**

**交互方式（三选一，建议按版本分档）**：

| 方式 | 难度 | 说明 |
|---|---|---|
| **A. 二选一** | ★ | "它由低纬流向高纬 / 由高纬流向低纬"。**简单直接，考的是寒暖流定义** |
| **B. 图上画箭头** | ★★ | 在图上**拖拽出一个箭头**，方向对了才算对。考的是**读图能力** |
| **C. 指定起点终点** | ★★★ | 从四个沿海地名中选出"它从哪里来、到哪里去" |

**建议**：初中版用 **A**，高中版用 **B**，尖子生挑战用 **C**。

> **为什么第二问必须有**：只考名称的话，学生可以纯靠背诵过关。
> 加上方向判定，就**强制学生理解"暖流＝低纬→高纬"这个定义**——
> 而这条正是洋流这一节的核心考点。

### 4.3 判定与容错

| 情况 | 结果 |
|---|---|
| 两问全对 | ✅ **起网**，按洋流品质结算 |
| 第一问错 | ❌ 鱼群散走，**本网作废**（消耗 1 次下网机会） |
| 第一问对、第二问错 | ❌ 鱼群散走，**但不消耗下网机会**（给一次补救式重问） |
| 两问都对但超时（每题限时 15 秒） | ❌ 按答错处理 |

> **容错设计的用意**：第一问错扣次数（方向性的知识错误要付代价），
> 第二问错不扣次数（方向是易混点，给学生"再想一次"的机会）。
> 这样既保持了压力，又不至于让方向题变成劝退点。

## 五、成功与失败的反馈机制

### 5.1 捕捞成功

**三秒反馈序列**（参照"合成复现"的思路，做成**必经流程**而非可选动画）：

```
第 0 秒  ── 渔网入水动画 + 水花
第 0.6 秒 ── 网中鱼影逐渐清晰，数量由品质决定
第 1.2 秒 ── 弹出【渔获卡 · 必看 2 秒】
             ┌──────────────────────────────┐
             │  🐟 鳀鱼 ×12                  │
             │  秘鲁寒流 · ★★★★★           │
             │  ────────────────────────    │
             │  为什么这里鱼多？             │
             │  这里盛行离岸风，表层海水      │
             │  被吹离海岸，深层冷水上涌，    │
             │  带来大量营养盐 → 上升补偿流  │
             │  ────────────────────────    │
             │  价值 +96        图鉴 +1      │
             └──────────────────────────────┘
第 3.2 秒 ── 卡片飞入右侧图鉴栏
```

**必看解释卡的用意**：学生在**捕到好鱼最高兴的那一刻**看到"为什么这里鱼多"，
记忆效果远好于课后讲解。**这是本作最重要的教学时刻。**

**成功音效分级**：
- ★×5：激昂音效 + 屏幕金光 + 鱼群满屏乱窜
- ★×4：明亮音效 + 光效
- ★×3 及以下：普通收网音

### 5.2 捕捞失败（分三种，反馈要各不相同）

| 失败类型 | 画面 | 文案 | 教学动作 |
|---|---|---|---|
| **第一问答错** | 鱼群受惊四散游走（有动画） | "认错了洋流，鱼群散了——这里是**秘鲁寒流**，不是巴西暖流。" | **立即显示正确答案 + 一行区别点**（"巴西暖流在南美**东**岸，秘鲁寒流在**西**岸"） |
| **第二问方向答错** | 渔网被水流冲歪，网口合不上 | "方向反了！秘鲁寒流是**寒流**，由**高纬流向低纬**。" | **在图上高亮那条箭头**，让学生亲眼看到方向 |
| **超时未答** | 鱼群自然游走（无惊吓动画） | "想太久了，鱼游走了" | 不作答错处理，可在结算里统计 |

> **失败反馈的核心原则**：**错一次就解释一次，且解释必须落在图上**。
> 光说"答错了"没有任何教学效果；把箭头在图上亮出来，学生下次就能自己找。

| 本格拉寒流 ↔ 加那利寒流 | 都在非洲西岸，一南一北分居赤道两侧 |
| 巴西暖流 ↔ 东澳大利亚暖流 | 都在南半球大洋西岸，分属大西洋/太平洋 |
| 日本暖流 ↔ 墨西哥湾暖流 | 都在北半球大洋西岸，分属太平洋/大西洋 |
| 西风漂流（出现 3 次） | **同一条流出现在三个环流里**，学生易误认为是三条不同的流 |

## 六、分级方案

| 维度 | **初中版** | **高中版** |
|---|---|---|
| **洋流范围** | **四个环流的 16 条**（北太平洋4 + 南太平洋4 + 北大西洋4 + 南大西洋4 + 印度洋3，西风漂流重复计） | **16 条 + 北印度洋季风洋流**，共 17 条位 |
| **新增内容** | — | 季风洋流（**随季节反向**，必须标注季节前提） |
| **判方向依据** | 只看红/蓝与纬度 | 加考**成因分类**：风海流 / 密度流 / 补偿流 |
| **第二问形式** | 二选一（向高纬 / 向低纬） | **图上拖拽画箭头** |
| **干扰项强度** | 只混同半球 | 同半球 + **同性质 + 同纬度带**（如寒流题里混进西澳大利亚寒流） |
| **时限** | 每问 20 秒 | 每问 15 秒 |
| **品质提示** | **显式显示星级**（看到 ★×5 就知道值得下网） | **不显示星级**，只显示水深/水色等间接线索 |
| **解释卡** | 保留（必看 2 秒） | 保留，但简化为一句话 |
| **下网次数** | 12 次 | 10 次（更紧） |
| **通关线** | 捕到 ★×5 鱼种（秘鲁寒流） | **集齐四大环流** + 捕到秘鲁寒流 |
| **启用层级** | **① 重点层 only** | **① 重点层 + ② 拓展层** |

> **两版都遵守第零条铁律的分层原则**（见 0.1）：
> **① 重点层的判定深度两版都必须完整**（那是考纲内容）；
> **② 拓展层只在高中版出现**，且**只认名称、不判方向**、界面标"拓展"角标。
> **初中版不含季风洋流**，因为季风洋流需要先理解季风环流，超出初中要求。

### 初高中知识点差异说明

| 学段 | 教材要求 | 在本游戏中的体现 |
|---|---|---|
| **初中** | 知道主要洋流名称与分布，能区分寒流暖流 | 认名称 + 二选一判方向（**重点层 16 条**） |
| **高中** | 理解洋流成因（风带、地转偏向力）、洋流对地理环境的影响（**渔场、气候、航行、污染**） | 图上画箭头（考成因）+ 成因分类 + 季风洋流 + 解释卡讲**渔场成因**；**增补拓展层（只认名称）** |

> **高中版可扩展的进阶玩法**（建议 v2 再加，全部对应教材"影响"四层面）：
> · **气候联动**：北大西洋暖流 → 西欧温带海洋性气候 / 摩尔曼斯克终年不冻港
> · **航行联动**：**顺流加速、逆流减速**（教材明确要求）；寒暖流交汇处多海雾
> · **污染联动**：加快净化速度，同时扩大污染范围
>
> 这四条全部有教材原文依据，不是自创规则。

## 七、关键设计要点（避坑清单）

### 7.1 教学准确性（最高优先级）

| 要点 | 说明 |
|---|---|
| **⛔ 洋流先分类再分层** | 见第零条铁律。**这是本游戏能否进课堂的前提**。① 重点层（16 条）详细讲、② 拓展层（约 6 条）简要提、③ 了解层（影响例证）只作说明 |
| **判据是"分几层"，不是"要不要删"** | 教材没出现的洋流**不必删**，但**必须降级呈现**（虚线 + "拓展"角标 + 不判方向）。真正要避免的是"把非考点当考点背" |
| **分层必须落在一眼可辨的视觉上** | 三层若长得一样，分层等于没做。⚠️ 这是最容易偷工减料的地方 |
| **严格照图 4-24** | 洋流名称、位置、寒暖性质、流向**以这张图为唯一真相源** |
| **寒暖流颜色不可乱** | 图中红＝暖流、蓝＝寒流。游戏中**必须沿用同一套颜色**，学生看着图玩游戏，颜色一致才能建立直觉 |
| **秘鲁寒流的反差要讲透** | "寒流却有大渔场"是本节最反直觉的点，**必须做成高光教学时刻**，不能只是一条普通纪录 |
| **"北半球冬季"这一前提** | 图的标题是《北半球冬季》。**涉及北印度洋季风洋流时必须说明季节**，否则讲错（该洋流随季节反向） |
| **西风漂流出现 3 次不是 3 条** | 它在南太平洋、南大西洋、南印度洋三个环流里是**同一条球状洋流**。数据建模时必须是**同一个 id**，不能建三条 |
| **洋流是全新主题** | 本仓库现有 12 个游戏源码中"洋流"出现 **0 次**，无既有实现可借鉴 |

### 7.2 玩法与动机

| 要点 | 做法 |
|---|---|
| **防止"乱点碰运气"** | 4 选 1 有 25% 蒙中率。**必须让下网次数成为稀缺资源**（只有 10~12 次），蒙错一次就少一次机会 |
| **防止只记颜色** | 干扰项里**必须混入同性质洋流**，否则学生看到红色就选暖流，不真读名称 |
| **顶级区要"值得跑一趟"** | 单网价值差 **20 倍**，这个差距不能再小 |
| **不要让方向题变成劝退点** | 第二问答错**不扣下网次数**，只给重问机会 |
| **失败反馈必须落在图上** | 光说"错了"没有教学效果，要把箭头高亮出来 |

### 7.3 与现有游戏的关系（避免重复建设）

按前一轮的分析结论：**不能再产"数据 + 4 选 1 + 图鉴 + 双人"的第 N 个复制品。**

本作的新骨架是：

1. **双层判定机制**——认名称 + 判方向，两关都过才生效。
   现有 `weather-quiz` / `province-quiz` 都是**单层判定**（选对即得分），本作是**链式判定**。
2. **空间决策 + 知识门槛的组合**——玩家要**在图上选位置**（空间决策），
   而位置的价值由**地理规律**决定（上升流 > 交汇 > 普通），答题只是"进门钥匙"。
   这个"**先选对地方、再答对题**"的复合结构是新的。
3. **反向强化**——现有游戏的答题是"答对加分"；本作的答题是**"答对才能拿到资源"**，
   知识从加分项变成了**准入门槛**，动机结构完全不同。

> **如果不能守住这三点，这个游戏就退化成了"答题 + 图鉴"的第 N 个变体，不值得做。**

### 7.4 实现工作量

| 模块 | 预估 | 可复用 |
|---|---:|---|
| 世界洋流图渲染（含箭头 + 颜色） | 500 行 | 新建（需按图 4-24 重绘矢量） |
| 洋流数据表（重点 16 + 拓展 6，含层级/鱼群/品质/成因） | 450 行 | 数据文件 |
| 双层判定 + 计分逻辑 | 300 行 | **纯逻辑可单测**，照 `china-relief/src/game.ts` |
| 图上选海域 + 画箭头交互 | 350 行 | 命中测试可借鉴 `china-relief/src/pick.ts` |
| 渔获卡 + 图鉴 | 300 行 | 结构照 `legend-match` 的图鉴 |
| 点名 / 轮流 / 结算板 | 300 行 | **可直接借鉴** `china-relief/src/session.ts` |
| 素材（鱼图标 15~20 种 + 洋流箭头） | — | SVG 绘制 |
| **合计** | **约 2,150~2,400 行** | 与 `legend-match`（2,343 行）同量级 |

**建议分阶段**：

| 阶段 | 交付 | 目的 |
|---|---|---|
| **P0** | 只做 **6 条重点层洋流** + 双层判定 + 起网结算 | **验证"答对才能捕鱼"这个机制好不好玩**。这是全案的生死点 |
| **P1** | 补齐**重点层 16 条** + 图鉴 + 分层视觉 | 初中版可用 |
| **P2** | 高中版（画箭头 + 季风洋流 + 同性质干扰）**+ 拓展层接入（只认名称）** | 分层体系完整 |
| **P3** | 高中进阶联动（气候 / 航行 / 污染） | 深化"洋流对地理环境影响" |

> **分阶段与分层的对应关系**：**P0/P1 只做重点层**（16 条），
> **拓展层（约 6 条）在 P2 才接入**。这是有意的——
> 先把考点打牢，再往里加拓展内容；反过来做会让早期版本显得"什么都考"。
>
> ⚠️ **P0 必须同时验证分层视觉**（重点层实心 vs 拓展层虚线），
> 哪怕 P0 里没有拓展层洋流，也要留出样式位——**否则分层的呈现纪律会在赶工时被忘掉**。
>
> **P0 的验证问题很明确**：如果"答题失败 → 鱼群散走"让学生感到**挫败**而不是**不甘心**，
> 就要调整——比如改成"答错后鱼群只是游远，可以追一网"。手感决定成败。
