## v1.1.0 改了什么（2026-09-23 上架）

一个需求：**把 73 个图例从"自绘图形"全部换成真实图片素材，要求风格统一、清晰美观，
且玩法与功能不变**。上一版 `v1.0.0` 的图例是项目自己用 SVG 画的（`scripts/make_legends.py`），
观感偏潦草；这一版改成**三类真实来源统一规格后重建**。

### 图例素材：自绘 SVG → 三类来源重建的 512×512 PNG

| 来源 | 覆盖 | 许可 |
|---|---|---|
| **教材图抠图** | 线条类与面状符号：国界 / 未定国界 / 省界 / 洲界 / 铁路 / 高速铁路 / 公路 / 高速公路 / 等高线 / 等深线 / 河流 / 湖泊… | 教材插图，仅供课堂教学 |
| **Iconify 图标库** | 点状/图形类：`mdi`（Apache-2.0）· `maki`（CC0）· `game-icons`（CC-BY-3.0，**已署名**） | 见左 |
| **按教材规范补绘** | 教材与图标库都没有的线状符号（`scripts/assetbuild/drawings.py`） | 本项目原创 |

**统一规格**：512×512 透明底 PNG、符号长边固定占画布 **78%**、线条粗细统一到
**长边的 6.3%**。73 个图例逐条量过，见 `scripts/assetbuild/README.md` 的授权表与「卡片上符号实际有多大」。

| | v1.0.0 | v1.1.0 |
|---|---|---|
| 素材格式 | 73 个 `.svg`（自绘） | **73 个 `.png`**（三类来源重建），`legends.json` 的 `image` 全部指向 `.png` |
| 底卡 | 画进每张 SVG 里（改一次要改 73 处） | **由 CSS 统一提供**，四个展示位（牌面 / 放大卡 / 图鉴缩略 / 图鉴详情）共用一套 |
| 线条粗细 | 各自定的，7 个主笔画低于自身规格 | 统一到长边 6.3%；细到"屏幕上 1 px 看不见"的 5 条线**按目标粗细重建** |

### 顺手修掉的两个真缺陷（都是这一版验证时量出来的）

1. **方形符号在牌面上被平切**。底卡是 `display: grid`，行轨道留了 `auto` ⇒
   `img` 的 `height: 100%` 跟轨道高度互相依赖、被判成 `auto` ⇒ 高度退回按素材
   1:1 比例算 = 宽度，得到 **151×151 的方盒塞进 151×112 的内容盒**，纵向溢出 39 px
   被 `overflow: hidden` 切掉。**只有方块状符号显形**（核电站三叶、水库三角、
   首都五角星、居民点 ◎●○ 阵列），横放的线状符号恰好落在框中间，完全看不出问题。
   修法：显式 `grid-template-rows/columns: minmax(0, 1fr)`。
   判据是**全量 73 × 2 档尺寸逐条量**（146/146 溢出 0），并配反证证明判据真会红。

2. **底卡内边距写成了百分比，实测是两拨值**。`padding` 的百分比按**各自的包含块**
   解析：`.lcard` 是绝对定位，包含块是整块牌面（1252 px）⇒ `4%` = 50 px，
   被 `clamp` 上限兜到 8 px；`.gallery-thumb` 的包含块只有 116 px ⇒ 4.64 px。
   于是"同一套底卡"实际是"缩略图 4.64 px、其余 8 px"，而且改上限就整体跳档。
   修法：写死 `6px`——四处**逐字节相同**，且比原来多给符号 4 px 净空。

### 玩法与功能：一行未动

关卡表（初中 4/6/8/10/12/14 对、高级 6/8/10/12/14/16 对）、抽牌与窗口算法、
难度曲线、计分与连击、提示次数、三种玩法（单人闯关 / 双人 PK / 图例图鉴）、
图鉴三档范围筛选、`legends.json` 的 73 条 id 与名称分类——全部保持不变。
`npm run test:data` 里 `layout.test` 19995 条、`pick.test` 462 条，**0 失败**。

### 验证

- **真机渲染回归**（Electron 离屏窗口驱动真实 `dist/web`，1280×820）：
  四个展示位的底卡**逐字节一致**（同底色 / 同边框宽色 / 同内边距 / 同内凹底槽）；
  73 个图例逐个 `new Image()` 体检，**加载失败 0**、非 `.png` 0、旧 `.svg` 引用 0；
  牌面从第 1 关走到末关（8 → 28 张卡）截图留档；提示态金色底与放大卡复现均正常。
- **全量裁切判据**：73 图例 × 2 档真实卡尺寸 = 146 条，`img` 盒**最大溢出 0 px**；
  反证（把行轨道注入回 `auto`）**146/146 条判红**，最大溢出 39 px ⇒ 判据不是空的。

  只能靠全量判据抓，靠翻截图抓不到。

## v1.0.0 改了什么（2026-09-23 上架）

两个需求：**① 把图例库补到覆盖教材标准图例页 + 初中必备图例，并保证名称/分类/图标一致；
② 加开局前的「初中组 / 高级组」模式选择**。上一版 `0.0.1` 的图例库是 60 条 / 7 类，
对齐之后是 **73 条 / 9 类**。

### ① 图例库 60 → 73

**先做差异核对，再动手**：拿教材「图 2.7 一些常用的图例」那一页（22 条）与旧库逐条对，
18 条已有、4 条缺；再按人教版八上附录的六组（居民点 / 境界线 / 水系 / 地形地势 / 交通 / 其他）
补出初中必备的缺口 9 条。

| 来源 | 新增条目 |
|---|---|
| 教材标准图例页缺的 4 条 | 居民点 · 洲界 · 高速铁路 · 关隘 |
| 初中必备缺口 9 条 | 等深线 · 海沟 · 板块界线 · 管道 · 输电线路 · 特别行政区界 · 赤道 · 南北回归线 · 南北极圈 |

合计新增 **13 个符号**（每个都是新写的绘制函数，不是复用旧图）。

**刻意没加**：军事分界线 / 停火线。它只在朝鲜半岛那类图上出现，且会把非地理话题拖进课堂 ——
需要时可以再加。

**分类 7 → 9**（对照教材附录重新分组，顺序即图鉴里的展示顺序）：

| | 旧 7 类 | 新 9 类 |
|---|---|---|
| 变化 | 行政区划与界线 / 地形与地貌 / 河流与水域 / 交通与航线 / 资源与人文 / 地图基础 / 气候图线 | **拆出**「居民点与城市」（居民点 / 首都 / 省级行政中心 / 一般城市 / 外国首都）<br>**拆出**「人文景观」（长城 / 关隘 / 名胜古迹 / 自然保护区）<br>「资源与人文」**改名**「资源与能源」 |

拆分的理由：旧库里"首都"和"国界线"算同一类、"长城"和"铁矿"算同一类，
让学生按类别回忆时对不上教材。

**名称与教材对齐**（2 处）：

- 国界线 → **国界**
- 省、自治区、直辖市界 → **中国省、自治区、直辖市界**（牌面简称仍是「省界」，小卡放得下）

教材把「时令河、湖」「常年河、湖」并成一条的写法，记录在各条的说明里，
卡片仍分「时令河 / 时令湖」「常年河 / 湖泊」四张 —— 符号形状本来就不同，
合成一张反而让学生认不出。

### ② 新增开局前的组别选择

| | 初中组 | 高级组 |
|---|---|---|
| 图例 | 54 条（`tier: basic`） | **73 条（全部）** |
| 关卡对数 | 4 / 6 / 8 / 10 / 12 / 14（整局 54 对） | 6 / 8 / 10 / 12 / 14 / 16（整局 66 对） |
| 候选窗口下限 | 3 类 | 2 类 |
| 面向 | 课本正文必会的常用图例 | 含细分辨形条目，同类干扰更强 |

**高级组 ⊇ 初中组**（不是两套互斥的题）：学生升组不丢基本盘，两组的分数也才可比。
组别**只在大厅选一次**，进游戏后只读显示 —— 一局成绩不能混用两套题库。

实现上组别落在 `MatchState.mode` 里、且 `main.tsx` 用 `key={mode}` 重挂载游戏组件：
状态机的"这一关算不算通"和"这是不是最后一关"都取决于组别，让它留在状态里 reducer 才自洽，
换组别时整体重挂载则保证不会沿用上一局。

### ③ 顺手修掉一个真缺陷：末关反而比倒数第二关松

难度曲线靠的是**同类干扰**（把候选池收窄到几类，一堆长得像的符号混在一起）。
旧代码的窗口起点是"关卡号 % 类别数"，类别按条目数降序排 —— 越往后轮到的类别越薄；
薄到凑不满本关对数时，代码会**临时并入更多类别**，窗口实际变宽、拥挤度反而下降。
类别从 7 涨到 9 之后这条式子触发得更早，实测量到：

| | 旧写法（起点一律轮转） | 新写法（只在够厚的起点里轮转） |
|---|---|---|
| 初中组末关拥挤度 | **3.56**（比第 5 关的 4.00 还低，曲线断了） | **4.67** |
| 高级组末关拥挤度 | 5.33 | **8.00** |
| 触发补类别的关卡 | 初中组第 6 关 / 高级组第 5、6 关 | **0 关** |

窗口公式同时换成按类别数等比收缩 `max(minWindow, ⌊类数 × 0.7^关卡⌋)`，
用 `floor` 而不是 `round` 以保证窗口单调不增。两组的完整曲线：

- 初中组：1.29 / 1.51 / 2.24 / 3.33 / 4.00 / 4.67
- 高级组：1.34 / 1.77 / 2.65 / 4.00 / 7.00 / 8.00

### ④ 图鉴加「范围」三档

`全部（73）/ 初中必备（54）/ 进阶条目（19）` 三档，**打开时的默认档跟着当前组别**
（初中组进来默认看必备，高级组进来默认看全部）。切到「全部」时，
19 条进阶条目会挂一枚金色「**进阶**」角标，一眼看出哪些是高级组才考的。
类别按钮只列出**当前范围内真有图例**的类别，不会给出点进去空白的类别。

### ⑤ 三个新符号做过实机复核后返工

符号是画出来的，只看源码文本判断不了"读起来像不像"，所以把 73 个符号渲染成
10 张对照图（新条目 280px、易混组 190px、全部 130px）逐张看了一遍，改掉三处：

| 符号 | 第一版画成了 | 改成 |
|---|---|---|
| 高速铁路 | 红底线 + **白色**枕木 ⇒ 纸色底上等于没有，读成"一串红方块/虚线" | 红底线 + **墨色**枕木（和铁路同构、只差颜色，这才是教材要考的那一点） |
| 管道 | 法兰环挨得太近，读成"一串珠子" | 环径 17→12、间距 42→50，中间加墨色内芯 |
| 板块界线 | 两个反向箭头离折线 74px，看着和线没关系 | 箭头挪到折线峰上方 30px |

另有三处**刻意不动**，各写了理由：山峰保留"等高线 + 峰顶三角"（光一个 ▲ 会和铁矿撞）、
四条界线共用同一条几何路径只差线型（否则学生能靠"弯不弯"蒙对，而真正要考的是线型）、
国界/未定国界保持实双线/虚双线。
