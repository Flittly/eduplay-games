# 经纬度五子棋

两位学生在经纬线构成的 15×15 棋盘上轮流落子。横线为纬线（北纬），竖线为经线（东经），
每个交点就是一组经纬度坐标。轮到某位学生时，先点击空交点，再当众报出该点坐标，
确认读对后才能落子；先连成五子者获胜。

## 玩法

- 棋盘范围：北纬 0°—70°、东经 60°—130°，经纬线每隔 5° 一条。
- 红方 / 黑方轮流落子，先连成五子获胜。
- 坐标确认页不会代读坐标，学生必须依据横纵轴自己读出来。
- 教师可在游戏内自定义胜方、负方和平局的积分。
