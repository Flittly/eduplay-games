# 经纬度五子棋

在经纬线构成的 15×15 棋盘上轮流落子。横线为纬线（北纬），竖线为经线（东经），
每个交点就是一组经纬度坐标。轮到学生时，必须在棋盘一侧输入对应的经纬度，
坐标正确且该点为空才能落子；先连成五子者获胜。

## 玩法

- 棋盘范围：北纬 0°—70°、东经 60°—130°，经纬线每隔 5° 一条。
- 红方 / 黑方轮流落子，先连成五子获胜。
- 落子必须输入交点的纬度与经度，例如「北纬30° 东经100°」。
- 坐标输入与落子记录放在棋盘一侧，不再遮挡棋盘。
- 支持双人对战，也支持“学生 vs 电脑”人机模式。
- 教师可在游戏内自定义胜方、负方和平局的积分。
