## v1.5.1 改了什么（2026-09-22）

老师报了两条：**「经度夹角的 0° 那个面那条线没画出来，角不是一个完整的角」**、
**「经纬度夹角的线都太细了，不醒目」**。

### ① 角现在是**闭合**的 —— 原先少了一条边

「经纬度是怎么量出来的」这一节里，角的两条边原来只画了一条：沿**选中点经线方向**的那条赤道半径。
经度角的两条边本该是「本初子午面 ∩ 赤道面」和「该点经线面 ∩ 赤道面」——**前者从来没画**，
所以经度弧的起点**悬在半空**，看着不像一个角。

顺手查出**同一毛病的第二处**：纬度弧画在半径 0.92 的位置，而那条边只伸到 `cos φ`
（北京 0.767）——**纬度弧的下端也是悬空的**。

修法：赤道面里的两条半径**一律画到赤道半径 1.0**。两条边等长、端点都落在赤道圈上，
两个弧的两端也就各自压在某条边上，角才算真正闭合。

### ② 夹角的线**加粗**了

`three.js` 的 `THREE.Line` 有个硬限制：`linewidth` 在 WebGL 下**被忽略**（永远 1 个设备像素），
所以「加粗」不能靠调线宽。改成**用管子画线**（`TubeGeometry`），于是既有真实粗细，
近大远小也正常。屏幕实测：**1.25px → 3.5~4.75px**。
角的顶点还加了一颗小球，让「夹角是从哪儿量出来的」一眼可见。

### ③ 边界情形不再"炸刺"

选中点正好落在**赤道**或**本初子午线**上时，夹角真的是 0°。此时零长度曲线的朝向是 NaN，
照画会在**满屏画出乱刺**。现在是：这种情况**不画线**（而不是画一条坏的）。

### 验证

- 夹角专项快检 **11/11 绿**；主回归 **72 → 82/82 绿**；`npm run test:data` **54/54 绿**。
- **反证**：把新补的那条 0° 边注释掉重建，4 条结构判据**同时变红**（11 条掉到 7 条）；
  还原后产物哈希逐字节一致 —— 证明这些判据真的咬得住，不是摆设。
- 截图：`P13-before-missing-zero-edge.png`（改前，缺 0° 边）·
  `P12-angle-clean.png`（改后）· `P12-angle-clean-thin.png`（几何相同、只把线宽调回旧值，作粗细对照）。

## v1.5.0 改了什么（2026-09-22）

> **上一版基线：v1.4.8**（把左栏三块合成「演示台」一栏、「俯视图」改名「极地投影」）。
> v1.5.0 = **七条需求一次做完** + 左右栏重排成三区。

### 一眼看变化

| # | 老师的要求 | 现在长什么样 |
|---|---|---|
| ① | 双色底图，海洋浅蓝、大洲深灰 | 「地表素材」里新增 **双色底图（大洲·海洋）** 档，可打印可投影 |
| ② | 背景加全白色 | 「太阳与画布」里新增 **纯白背景（投影·打印）**，与「星空背景」互斥 |
| ③ | 地轴要能摆到垂直 | 「地轴倾角与太阳直射点」里新增 **地轴倾斜 / 地轴垂直** 两档 |
| ④ | 要一张经纬度二维平面位置图 | 右栏「控制台」新增 **经纬度位置图** 一节 |
| ⑤ | 透明地球 + 经纬度夹角演示 | 右栏「经纬度是怎么量出来的」新增 **透明地球**、**夹角演示** 两个开关 |
| ⑥ | 经纬网疏密要能调 | 「经纬网」那一列新增 **30° / 15° / 10° / 5°** 四档 |
| ⑦ | 左右栏重排、能加下边栏 | 版面改成**左栏「演示台」／舞台／右栏「控制台」+ 底部栏**三区 |

### 逐条说明

**① 双色底图（大洲深灰 / 海洋浅蓝）**
新素材 `public/textures/earth_base.png`，只分大洲与海洋两种情况，与卫星影像同投影同尺寸，
可共用 UV。图源用 Natural Earth 的 10m 陆地数据集自己栅格化 —— **只画自然海陆、零政治边界**，
不需要瓦片、不需要 Key，也便于投影打印时看清水陆轮廓。

**② 纯白背景（投影·打印）**
把画布背景从深空改成纯白。它和「星空背景」互斥（白底上看不见白色星点，所以星空那条会被自动禁用）。
注意**「纯白地球」故意没有跟着禁用**：白球 + 白底 + 经纬网 = 一张可直接投影/打印的经纬网图，
这正是这个档位存在的理由，禁用等于砍掉能力。

**③ 地轴倾斜 / 地轴垂直**
默认档是倾斜 23.5°（真实地球）。新增的垂直档让地轴垂直于轨道面 ——
这时直射点终年落在赤道、全球终年昼夜平分、极地没有极昼极夜。
**把两档对着看，"地轴倾斜才是四季成因"这句话才立得住**，比口头讲一遍有用得多。

**④ 经纬度位置图**
右栏新增一节：一张等距圆柱投影的平面图，**红点＝选中的点**、**橙点＝太阳直射点**、
**黄线＝晨昏线**。三维球会随自转把背面转走，二维图任何时候都能一眼看全。

**⑤ 透明地球 + 经纬度夹角演示**
- **透明地球**：整球压到半透明（并停掉深度写入），背半球被挡住的经纬线能直接透出来。
- **夹角演示**：在球里画出「纬度是哪个角、经度是哪个角」—— 两条弧 + 两条边。
  右侧同时给一张**二维剖面示意图**，避免三维图转到背面就看不见。
- 还没在球上选点时，用**北京**当示例点，保证这一节永远有东西可讲。

**⑥ 经纬网疏密四档**
30° / 15° / 10° / 5°（原来是写死 15°）。注意换档位是**整组重建经纬网**，
不是把线藏起来 —— 30° 和 5° 根本不是同一批几何体。

**⑦ 版面重排成三区**
**左栏「演示台」**（动手改：公转与自转 / 地轴倾角与太阳直射点 / 视角与投影）、
中间舞台、**右栏「控制台」**（只读：坐标与地方时 / 经纬度位置图 / 经纬度是怎么量出来的 / 公转与四季），
底部为正常流里的一条栏。
分工一句话：**左边改，右边读**。

这次重排顺带治了一个老毛病：v1.4.6 左栏会重叠 135px，病根是四块浮层各自绝对定位、只能靠调魔数互不重叠。
现在底部栏是**正常流兄弟**，结构上不可能重叠。

### 同日补修：夹角标签叠在一起

「纬度 xx°」「经度 xx°」「地方时」三个标签原来都在同一条射线上，只靠半径 0.93 / 1.12 / 1.50 区分。
**纬度接近 0° 时纬度弧退化成一点**，三个标签就挤到一块（最差相交 26.9px，而且 6 个自转角里只有 4 个看得出
—— 换个角度就"没事"，最容易被当偶然放过）。
修法是**按屏幕纵坐标排序后逐个下推**（间距 6px，保留原有次序）；修后 6 个自转角 × 2 个采样点全部 0px。

### 特意**没做**的事（免得后人"顺手对称"）

- **没给「纯白地球」加禁用**（理由见 ②）。星空加了，白球没加，这是有意的。
- **商城简介没动**（147 字，一次写定规则）；逐条核对后它仍然准确 —— 左栏「演示台」仍是三节，
  简介点名的三样（公转与自转旋钮 / 直射点回归曲线 / 极地投影）都还在。

### 验证

- 真实渲染回归 **65 项全绿**（后来又补了标签让位的判据 → 72 项）；
  覆盖产物指纹、三区布局与对齐、双色底图"屏上颜色＝素材原色"、纯白背景四角取像素、
  地轴两档与公式对账、位置图红点与投影函数一致、夹角弧的圆心角＝经纬度本身、
  疏密四档线数＝公式、窄屏/宽屏、零报错。
- `npm run test:data` **54/54 绿**；`scripts/roster-guard.cjs` **25/0**。
- 截图归档 `screenshots/v1.5.0-01..10-*.png`。

## v1.4.8 改了什么（2026-09-19）

（作为 v1.5.0 的对比基线，一并留档）

- **合并**：左侧「旋钮 / 直射点 / 俯视图」三张卡合成**一张「演示台」卡**，内含三节，
  每节仍可单独折叠（矮屏下把上面几节收掉，就能把极地投影顶进可视区）。
- **改名**：「俯视图」→「**极地投影**」；「北极朝下看 / 南极朝上看」→「**自北极俯视 / 自南极俯视**」。
  两块画布各配一行读数，直接读出**极昼 / 极夜 / 昼夜平分**。
- **「整齐」是可量化的**：旧版三块右边缘实测 214 / 214 / 170（第三节 `width:auto` 缩到只剩 170），
  右边空出 44px —— 这才是"不齐"的根源。改成两栏**共用同一套 CSS 规则**后，三节右边缘 203/203/203，
  左右边缘偏差都是 0px。
- 真实渲染 36 项全绿；`npm run test:data` 54/0；双端上架 v1.4.8。
