## 新游戏：地貌人格测试（landform_quiz）v1.0.0 —— 开发、实测、双端上架
需求（用户原话要点）：答题（约 15 题）判断性格像什么地貌；分国内/国外；答题后看结果、展示地貌**真实照片**；左侧一栏介绍"这是什么/特点"并用**微缩地图红点**标位置；先设计一种便于扩展的数据结构（json 还是 txt），照片放相对目录、json 引用路径。

### 数据与算法
- 目录 `E:\Self\workspace\eduplay-games\landform-quiz`，复制 earth-globe 骨架（React 19 + TS + Vite 8，无 three.js）。
- `public/data/landforms.json`：40 处地貌（国内 20 + 国外 20），字段 id/name/en/category/type/country/region/lat/lon/photo/photoSource/summary/intro/traits[]/cause/personality/profile。顶部 `_README` + `dimensions` 说明结构；新增地貌只需改 json + 丢一张图，**不用改代码**。
- `public/data/questions.json`：15 题 × 3 选项，每个选项按维度给 delta。
- **五维人格模型**（地貌属性↔人格侧面）：thermal 温度（冷静内敛↔炽热张扬）、relief 起伏（平和低调↔高远出众）、hardness 质地（柔韧随和↔刚强棱角）、dynamics 动态（沉静恒定↔激荡多变）、moisture 水意（独立自持↔丰盈亲和）。
- 匹配：选项 delta 求和 → 按「每维理论上限 × 0.62 折扣」归一到 0-100（自动归一，**不需要手工维护权重**）→ 五维欧氏距离排序 → score = 1 - d/(√5×100)，下限 30%。
- 校验通过：40 地貌 id 唯一、字段齐全、坐标合法；15 题理论上限 {thermal:12, relief:10, hardness:12, dynamics:14, moisture:16}。

### 真实照片采集（scripts/fetch_photos.py）—— 本轮最折腾的部分
- **必应不可用**：`cn.bing.com/images/search` 反复抓取后返回反爬干扰页/无关明星图（搜"科罗拉多大峡谷"返回 21 Savage、王菲）。
- **百度 acjson**：结构清晰（replaceUrl[0].ObjURL 为原图、hoverURL 固定 760px），但直接请求会被风控拦成 `{"antiFlag":1,"message":"Forbid spider access"}`；需先带 cookie 预热（访问首页 + 结果页拿 BAIDUID）再带 `X-Requested-With` 调接口。
- **最终主源 = 360 图片** `https://image.so.com/j?q=..&src=srp&sn=0&pn=30`：**无需 cookie**、一页 55~60 条、字段干净（img 原图 / thumb 缩略图 / width / height / title），`sn` 翻页。百度接口降级为备源（360 候选 <6 时补一轮）。
- 过滤规则：排除 AI 生成图（isAigcEdit / aigc、bcebos miaobi 域名、标题含"AI生成"）、商业图库水印图（vcg/699pic/千图/veer/视觉中国…）、以及"比大小/排行"凑数图（标题含 寿光/静山/对比/排名/vs）。排序：**关键词命中 > 横构图(≥1.25) > 宽度大**，取前 14 个候选逐个试下（原图→缩略图），下载用 Referer `https://image.so.com/`。
- 统一裁 16:10、压到 900px 宽、quality 78；写 `.tmp` 校验通过再原子替换；全局 USED_SOURCES 去重；`--force/--only=/--sheet` 参数；`--sheet` 生成 montage.jpg 供人工复核。
- 两次修正才能用：① 下载逻辑漏删孤儿 `.tmp`（tmp2 成功时 tmp 残留，会混进打包目录）→ 加 `_clean_tmp()`；② 逐张肉眼复核 montage，重取 tianshan（落到铜版画/经幡）、wudalianchi（落到石碑）、uluru（落到骆驼/灌木）、qiantang_tide、dead_sea，最终 40/40 全部为实景照片。
- **经验：不要只看"下载成功"就算完，必须生成拼版缩略图逐格目视复核**，否则会大量混入无关图。
