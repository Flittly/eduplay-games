### 数据与算法
- 目录 `E:\Self\workspace\eduplay-games\landform-quiz`，复制 earth-globe 骨架（React 19 + TS + Vite 8，无 three.js）。
- `public/data/landforms.json`：40 处地貌（国内 20 + 国外 20），字段 id/name/en/category/type/country/region/lat/lon/photo/photoSource/summary/intro/traits[]/cause/personality/profile。顶部 `_README` + `dimensions` 说明结构；新增地貌只需改 json + 丢一张图，**不用改代码**。
- `public/data/questions.json`：15 题 × 3 选项，每个选项按维度给 delta。
- **五维人格模型**（地貌属性↔人格侧面）：thermal 温度（冷静内敛↔炽热张扬）、relief 起伏（平和低调↔高远出众）、hardness 质地（柔韧随和↔刚强棱角）、dynamics 动态（沉静恒定↔激荡多变）、moisture 水意（独立自持↔丰盈亲和）。
- 匹配：选项 delta 求和 → 按「每维理论上限 × 0.62 折扣」归一到 0-100（自动归一，**不需要手工维护权重**）→ 五维欧氏距离排序 → score = 1 - d/(√5×100)，下限 30%。
- 校验通过：40 地貌 id 唯一、字段齐全、坐标合法；15 题理论上限 {thermal:12, relief:10, hardness:12, dynamics:14, moisture:16}。

### 照片采集：v1.1.0 最大的坑（三条经验）
- **图库水印的真正入口是"缩略图兜底"**：`rank_candidates` 里原本写的是「obj 和 hover 都不可用才丢弃」，于是当原图（ObjURL）来自带水印的商业图库、而 hover 是 360 CDN 缓存的同一张图时，脚本会退而下载**同一张水印图**。修正为：`obj` 命中水印域名即整条丢弃。
- **水印图库的域名特征**：`icweiliimg*.pstatp.com/weili/...`（图虫/微利图库，今日头条 CDN）、`hellorfimg.zcool.cn`（站酷海洛）、`hdslb.com`（B 站视频帧，常带播放控件/标题字）。这些要进 `WM_HOST_HINTS`；它们的图往往尺寸大、横构图，排序靠前，不拦就会大量入选。仅看 URL 也拦不住全部——360 自家 CDN（`qhimgs1` / `so.qhimg`）也会缓存这些水印图。
- 新增两个复核工具参数：`--avoid=子串`（拉黑单张图源，命中 obj/hover/title）、`--avoid-host=域名`（本次运行整体排除某 CDN）。发现坏图时用它逼脚本换下一张候选，比换检索词有效得多（检索词小改不会改变排序结果，同一张图仍排第一）。
- **拼版小图看不清水印**：210×132 的 montage 只能判断"内容对不对"，水印要看大图。复核水印时改用 4 列 × 340px 的拼版，或直接看单张原图。本轮共重取 11 张（泰山带红字水印、黄山是晚霞、三清山"鸟瞰八桂"、茶卡有黑边、青海湖主体是草地、可可西里/德纳里不典型、华山/优胜美地/多洛米蒂三张图虫水印、华山航拍带红色标题字、百内主体是原驼）。最终 80/80 实景、无水印；只有多洛米蒂受限于可用图源是 640px（内容是多洛米蒂群峰＋湖面倒影，接受）。

## 派生「公网版」：新建独立仓库 `E:\Self\workspace\landform-quiz-web`

用户希望：单机/平台版保持不动，另做一份能对公众开放访问的版本，并想买域名。

- **关键事实（决定了整条路线）**：这个游戏是**纯静态、零后端**——`src/` 里唯一的 `fetch` 是读本地 JSON（`assetUrl` 基于 `document.baseURI`），`vite.config.ts` 用 `base: "./"`，平台通信有 `if (window.parent && window.parent !== window)` 守卫、`roster` 为空时不显示学生名。**所以它脱离平台可直接单独打开，公网版无需改任何游戏代码，也不需要服务器/数据库。**
- 分叉方式：把 `src/ public/ scripts/ index.html package.json package-lock.json tsconfig.json vite.config.ts` 复制到 `E:\Self\workspace\landform-quiz-web`（**排除** `node_modules`、`dist`、调试用的 `montage*.jpg` / `review-*.jpg` / `screenshots/`）。原游戏 README 存到该仓库 `docs/游戏说明.md`。分叉点 = v1.1.0，**之后两边改动不会自动同步**，已在 README 顶部写明。
- 为公网化新增：`index.html` 的 description / theme-color / favicon / og / twitter 分享标签（og:image 留了"绑域名后换绝对地址"的注释）；`public/_headers`（缓存 + 安全头，**特意不加 `X-Frame-Options: DENY`**，否则平台 iframe 嵌不进去）；`netlify.toml`；`.gitignore`；`README.md`；`DEPLOY.md`（全套上线与域名指引）。
- 构建验证：`npm install`(24 包) + `tsc --noEmit && vite build` 通过 → `dist/web` 1.60kB html / 15.01kB css / 236.40kB js，共 7.3MB、80 张照片 + 2 地图 + 2 数据 + `_headers` 全在。
- 浏览器实测（7915，静态服务）：标题已换新；首页 `80 种地貌`、题库 40/40/80、5 维；答题 15 题；结果页「丹霞山 75%」、5 根人格条、3 张相近地貌、照片 naturalWidth=900、地图源 = 阿里云 DataV。→ 公网版与平台版渲染一致。
- 上线结论（写给用户）：**上线快慢取决于托管平台，与有没有域名无关**。静态托管会免费送子域名，所以最短路径是「先上线拿链接、后买域名」；买域名后走 CNAME 绑定 + 自动 HTTPS。唯一真正的分叉是**备案**：大陆托管必须 ICP 备案（约 2~3 周，且个人备案做"教育"类内容有被要求补资质的风险）；海外/香港托管免备案、当天可上线，代价是大陆访问速度中等、微信内分享可能被提示。详见该仓库 `DEPLOY.md`。

## 容量评估：公网版能不能抗住大量访问（2026-09-12 实测）

用户问"在线版本是否抗得住大量人访问"。不靠感觉，四步实测，结论如下。

**体量基线**：站点 7.3MB = 照片 6.58MB（80 张 / 均 84KB）+ JS 232KB + CSS 15KB + data 132KB + maps 68KB。
**首访实际传输 149.6 KB**（gzip 后：JS 231→72KB、landforms.json 124→43KB）；图鉴全滚完最多 6.6MB，靠 `loading="lazy"` 逐张加载。

**服务链路实测**：`Server: CloudStudio Gateway` + 腾讯云 EdgeOne。HTML/JS/CSS/JSON/照片在首次访问后**全部 `Eo-Cache-Status: HIT`**
（重新部署后第一次 MISS/RefreshHit 属正常，多请求几次即转 HIT）。网关启用了 **Brotli**。

**并发探测**：小文件 300 请求 / 并发 100 → 100% 成功、221 req/s、p99 688ms、**零限流**；
照片 100 请求 / 并发 25 → 100% 成功；连续 12 次 TTFB 稳定 224~330ms（**无冷启动抖动**）。
⚠️ 单机吞吐受限于本机上行（8.5MB/3.2s ≈ 21Mbps），故 221 req/s 是**客户端天花板**，只能说明"未触发限流"，不可外推成承载人数。

**两条硬发现**（要写进结论）：
1. 发布通道**无 SLA / 无容量承诺**，源站是**单个沙箱容器**；缓存未命中时仍回源到这个单点。
2. `public/_headers` 在该通道**不生效**（那是 Netlify/CF Pages 约定）——实测响应头**无 `Cache-Control`、无 `ETag`**，无法 304，
   重复访问/刷新会重新拉资源（但打在 CDN 边缘，不影响源站）。

**给用户的结论**：一个班/一个学校几百人没问题；上千人靠 CDN 命中也能撑，但偶发冷启动可能让首屏失败（已由"永不白屏"兜底提示重试）；
要长期稳定必须迁到自有托管（Cloudflare Pages / 对象存储 + CDN + 自有域名）。
加固优先级：① 迁托管 ② 照片转 WebP（6.6MB→约 3MB）③ 图鉴分页或虚拟滚动。
