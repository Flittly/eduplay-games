- manifest.json 是插件契约：gameCode/name/version/type=iframe/sdkVersion=1/entry=web/index.html/backendPlugin=null/min、maxPlatformVersion。
- 与平台（E:\Self\workspace\eduplay，Java 后端 + Vite 前端）通过 postMessage 通信：
  - 游戏 → 平台：GAME_READY（gameCode+version）；GAME_COMPLETE（roundId UUID 幂等、score、correctCount、totalCount，可带 studentId/timeSeconds）；GAME_SESSION_COMPLETE（results 数组，含 mistakes）。
  - 平台 → 游戏：GAME_INIT，payload 含 gameCode/version/roster（studentId、studentName、className、studentNo），兼容旧版单学生字段。
  - source 固定 "eduplay-game" / "eduplay-platform"。
- 平台侧 GamePage.tsx 收到 GAME_READY 后 sendInit；GAME_COMPLETE 走统一积分接口 POST /api/v1/games/{gameCode}/scores（roundId 幂等）。
- 插件分发：backend/plugins/packages/{gameCode}-{version}.zip，安装到 backend/plugins/installed/{userId}/{gameCode}/{version}，前端用 GET /api/v1/plugin/{token}/{gameCode}/{version}/{entry} 以 iframe 加载。
