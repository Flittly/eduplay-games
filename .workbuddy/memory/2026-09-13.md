## solar-system v1.1.0：拉开木星-土星间距 + 卫星名称 + 卫星轨道开关

用户反馈三点：①木星和土星太近，卫星看起来要撞上；②卫星没有名称标注；③卫星轨道无法关闭。

### 1) 间距（根因是显示压缩，不是数据）

- 轨道显示半径 = `7.2 * aAU^0.45`。木星 15.12 / 土星 19.88，两者**最小中心距只有 4.21**
  （含偏心率、倾角，按 3 个土星周期采样求得），而两者最外侧卫星轨道半径之和是
  2.99 + 2.85 = 5.84 → 轨道圈必然相交，最坏重叠 1.63。
- 新增 `BodyData.orbitOffset`（显示用轨道半径微调）。**土星/天王星/海王星各 +2.0**，
  三者同步外移可保持彼此相对间距不变，木星不动（动了会挤压小行星带）。
  木星-土星最小中心距 → 6.23，净余量 +1.32；土星-天王星 2.38、天王星-海王星 1.94
  都反而更宽松了。
- 同时缩小卫星轨道铺展系数 `2.5/0.14/0.18 → 2.0/0.12/0.15`，并让有光环的行星
  （土星 2.35、天王星 2.0 倍率）的卫星从光环外侧起步。

### 2) 卫星名称（这是个真 bug）

- 标签可见性原本只在「图层变化」时由 `setLayers()` 重算，而它读的是 `engine.selected`；
  选中行星只调用 `engine.select()`，**不会重算** → 卫星名称永远不显示（除非顺手点了某个图层开关）。
- 抽出 `applyLayerVisibility(layers)`，在 `setLayers` 与 `select()` 里统一调用；标签字号
  0.8 → 0.92。现在点击任意行星，它的卫星名称立即出现（木卫一~四、土卫二/五/六/八…）。

### 3) 卫星轨道开关

- `LayerState` 新增 `moonOrbits`，图层面板顺序为「行星轨道 / 天体名称 / 卫星 / 卫星轨道 /
  小行星带 / 柯伊伯带 / 星空背景」。关掉「卫星轨道」只隐藏轨道圈，卫星本体与名称保留。

### 验证（真实渲染，非静态骨架）

- 用 Electron + SwiftShader 软渲染跑真实构建产物，先 Node 复刻同一套公式算出理论值，
  再让页面 `__solarDebug.readBody()` 输出实测值：木星 `[-15.392,0.087,-3.806]`、
  土星 `[-21.338,0.245,-5.643]`、中心距 6.225，**与理论值逐位一致**。
- 截图确认：最接近时刻两者卫星轨道圈明显分离；木星四颗卫星名称全部显示；关闭「卫星轨道」
  后轨道圈消失而卫星仍在；关闭「卫星」后卫星完全隐藏；两个开关都能恢复。
- 新增 `__solarDebug.frame(bodyIds, distance, elevation)` 取景辅助，方便后续视觉验证。
- 双端上架：7070/17070 均 v1.1.0 ACTIVE，教师端商城可见。commit `70bded5`。

## 寰宇太阳系 v1.1.1 + 寰宇地球仪 v1.4.2（本轮：6 项界面修复 + 简介精简 + 双端上架）

### 做法

**太阳系 v1.1.1**

- **标签被裁的真因不在标签本身，而在贴图画布宽度**：`makeLabelTexture` 只按主标题
  `measureText(text).width` 定画布宽，副标题（"恒星 · 太阳系的中心"）比主标题宽，
  **超出画布右缘直接被裁掉**。改为同时量主/副标题、取最大者 + 留白。
- 删 `<header class="solar-title">` 整块与对应 CSS；`.solar-hud` 的 `top` 从 108px 收回 16px
  （原先是为了给标题让位才压低）。
- 三栏（`.solar-hud` / `.solar-panel` / `.solar-hint`）各加 `.panel-toggle` 胶囊按钮 +
  React `open` 状态，收起时加 `.is-collapsed` 且**不渲染 `.panel-body`**（不是 `display:none`）。
- 太阳标签副标题从"恒星 · 太阳系的中心"缩为"太阳系的中心"：原副标题把画布撑到 315px 宽，
  横向压住金星；缩短后画布 202×115（副标题宽 168），不再压到别的天体。

**地球仪 v1.4.2**

- **纬线标签被切半的真因**：标签精灵是一块"正对镜头的平面"，地球是弧面。贴着球面摆放时，
  标签靠盘心一侧会扎进地球前半面之下，被判定为被遮挡 → 文字被切掉半截（赤道这种短标签没事，
  南北回归线这种长标签断在中间）。修法：`sprite.material.depthTest = false; depthWrite = false;`
  —— 但要**配套每帧的真实遮挡判定**（`front = 点·相机方向`，`front < -0.02` 就整个 `visible=false`），
  否则会"透过地球看见字"。

### 本轮踩的坑

- **并行编辑同一文件会互相覆盖**：这轮 `EarthGlobe.tsx` 上连着做多处 Edit，有 4 处改动被后续 Edit
  悄悄覆盖（`ViewKey` 少了 `"north"|"south"`、`parallelLabels` 丢了 `text` 字段、`latLabel` 被改回
  `labelAt`、`__globeDebug` 丢了 `readLatLabels` 钩子），构建报 TS2304/TS2367/TS2322，得逐个补回。
  **教训：同一文件的多处改动尽量一次想全、改完立刻 build；不要"改一处跑一次验证"。**
- 极地俯视第一版只做了"整圈取最左点"，结果几条同心圆的标签会**挤在同一条水平直径上互相叠字**
  （赤道与回归线的屏幕半径只差 8%，必然重叠）。改成按屏幕方位角扇形错开后解决 —— 这类
  "同心圆注记"问题，**沿半径方向错开是不够的，要沿方位角错开**。
- 本机 `date` 输出 2026-09-13，而会话头部 `<current_time>` 写的 2026-09-08。**以文件 mtime / `date`
  为准**写记忆文件名，别信会话头。
