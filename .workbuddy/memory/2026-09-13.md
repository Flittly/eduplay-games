## solar-system v1.1.0：拉开木星-土星间距 + 卫星名称 + 卫星轨道开关

用户反馈三点：①木星和土星太近，卫星看起来要撞上；②卫星没有名称标注；③卫星轨道无法关闭。

### 1) 间距（根因是显示压缩，不是数据）

- 轨道显示半径 = `7.2 * aAU^0.45`。木星 15.12 / 土星 19.88，两者**最小中心距只有 4.21**
  （含偏心率、倾角，按 3 个土星周期采样求得），而两者最外侧卫星轨道半径之和是
  2.99 + 2.85 = 5.84 → 轨道圈必然相交，最坏重叠 1.63。
- 新增 `BodyData.orbitOffset`（显示用轨道半径微调）。**土星/天王星/海王星各 +2.0**，
  三者同步外移可保持彼此相对间距不变，木星不动（动了会挤压小行星带）。
  木星-土星最小中心距 → 6.23，净余量 +1.32；土星-天王星 2.38、天王星-海王星 1.94
  都反而更宽松了。
- 同时缩小卫星轨道铺展系数 `2.5/0.14/0.18 → 2.0/0.12/0.15`，并让有光环的行星
  （土星 2.35、天王星 2.0 倍率）的卫星从光环外侧起步。

### 2) 卫星名称（这是个真 bug）

- 标签可见性原本只在「图层变化」时由 `setLayers()` 重算，而它读的是 `engine.selected`；
  选中行星只调用 `engine.select()`，**不会重算** → 卫星名称永远不显示（除非顺手点了某个图层开关）。
- 抽出 `applyLayerVisibility(layers)`，在 `setLayers` 与 `select()` 里统一调用；标签字号
  0.8 → 0.92。现在点击任意行星，它的卫星名称立即出现（木卫一~四、土卫二/五/六/八…）。

### 3) 卫星轨道开关

- `LayerState` 新增 `moonOrbits`，图层面板顺序为「行星轨道 / 天体名称 / 卫星 / 卫星轨道 /
  小行星带 / 柯伊伯带 / 星空背景」。关掉「卫星轨道」只隐藏轨道圈，卫星本体与名称保留。

### 验证（真实渲染，非静态骨架）

- 用 Electron + SwiftShader 软渲染跑真实构建产物，先 Node 复刻同一套公式算出理论值，
  再让页面 `__solarDebug.readBody()` 输出实测值：木星 `[-15.392,0.087,-3.806]`、
  土星 `[-21.338,0.245,-5.643]`、中心距 6.225，**与理论值逐位一致**。
- 截图确认：最接近时刻两者卫星轨道圈明显分离；木星四颗卫星名称全部显示；关闭「卫星轨道」
  后轨道圈消失而卫星仍在；关闭「卫星」后卫星完全隐藏；两个开关都能恢复。
- 新增 `__solarDebug.frame(bodyIds, distance, elevation)` 取景辅助，方便后续视觉验证。
- 双端上架：7070/17070 均 v1.1.0 ACTIVE，教师端商城可见。commit `70bded5`。

## 遇到的问题（本轮新增）

- **同一文件的多处 Edit 并行下发会互相覆盖**：一次消息里发两个针对同一文件的 Edit，
  只有最后一个生效（Jupiter 的 offset 没删掉、Uranus 的 offset 没写进去，静默失败）。
  之后改成逐个执行 + `grep` 复核，才定位到。**教训：批量编辑同一文件必须串行，并在编辑后核对文件内容。**
- 静态服务不要写成 `python -m http.server ... &`，父 shell 结束会被收掉，
  Electron 报 `ERR_CONNECTION_REFUSED`，白跑一轮。要用独立的常驻任务并先 `curl` 探活。
- Electron 跑 WebGL 必须 `no-sandbox` + `disable-gpu-sandbox` + swiftshader 三件套；
  只给 swiftshader 会 `RENDERER GONE killed`。已补进 skill `frontend-visual-verify`。

### 本轮踩的坑

- **叠加球壳色带几乎看不见**：着色器内部用「over」预乘了 alpha，又用默认 NormalBlending
  再乘一次 → 等效 alpha²（0.22 → 0.048）。改用 `CustomBlending + OneFactor +
  OneMinusSrcAlphaFactor` 后正常。已在 MEMORY.md 记下排查手法。
- **截图里标记点"消失"**：地球仍在 60°/秒自转，点击后等 1.2 秒再截图，标记已随球面转到
  背面。**教训：验证带持续动画的场景前，先停掉动画再操作与截图**，否则会误判成功能坏了。
- **合成 PointerEvent 会让 OrbitControls 抛 NotFoundError**：`setPointerCapture` 需要活跃
  指针。改用 Electron `webContents.sendInputEvent` 发真实 mouseDown/Move/Up，既没报错，
  也更接近真人操作（本轮旋钮 ±90°/±60° 的拖动就是这么测的）。已补进 skill。
