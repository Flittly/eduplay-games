## 寰宇地球仪 v1.2.0：昼夜四季教学升级（上午）
- 需求：①赤道/回归线/极圈/本初子午线用鲜艳颜色并显示经纬度标签；②晨昏线+真实昼夜；③太阳直射点/直射带+四季切换+可见太阳。
- 实现（earth-globe/src/EarthGlobe.tsx 全量重写）：
  - 线条配色改高饱和（赤道 #ff3b30 / 回归线 #ffa502 / 极圈 #2ee6ff / 本初子午线 #8f6bff），管径加粗；makeLabelSprite 生成文本精灵（自动测宽，默认 worldScale 0.115），赤道/回归线/极圈标签放东经 105°（面向默认视角），子午线标签放北纬 42° 的 0° 与 180°。
  - 地球改 ShaderMaterial：uniform uSunDir（世界坐标），fragment 里 dot(法线,太阳方向) smoothstep 映射昼/夜，夜侧 day*0.10+深蓝；纹理 colorSpace 用 NoColorSpace（自定义 shader 无输出编码）。图层开关改 uniforms.uHasTex。
  - 晨昏线：TorusGeometry(1.006) 四元数 setFromUnitVectors(+Z→sunDir)，场景级（不随地轴倾斜），金色 #ffd34d，标签放最面向相机的一侧（64 步采样最大 dot）。
  - 太阳：球体+径向渐变光晕精灵+标签，距离 3.6（拉近距离使其在缩放中可入镜），方位固定东经 15°（与默认视角 105° 成 90°，晨昏线纵贯视野中央昼夜各半）；直射光线虚线 + 落点光斑 + 直射点标签（纬度随滑杆实时重建）；直射带 = 南北回归线间半透明圆柱（tiltGroup 子级）。
  - setSunDeclination(decl)：sunDir = cosδ*方位向量 + sinδ*地轴向量（世界坐标），一次性更新太阳位置/光线/晨昏线/直射点/着色器 uniform。
  - UI：新增"太阳与四季"区（春分/夏至/秋分/冬至按钮 + 直射点纬度滑杆 -23.44~23.44 + 说明文字）；按钮高亮按 |decl-季节值|<0.05 判定（春分秋分同为 0 均高亮）；LayerState 增 terminator/sunDisplay/subsolar/zone 四项。
- 版本 1.2.0（manifest + main.tsx），描述更新。打包脚本 .workbuddy/tmp/pack_earth.py（单游戏打包，dist 只留最新）。
- 上传 7070/17070 双端 POST /api/v1/admin/games/earth_globe/packages，产品版本自动升至 1.2.0 ACTIVE，教师端商城可见 1.2.0。
- 实测截图（agent-browser）：夏至默认视图（左侧昼右侧夜、晨昏线居中、直射光线射向北回归线）、冬至（太阳从南射来、直射南回归线）、春分（晨昏线过两极、直射赤道）、滑杆 -12°（南纬 12.0° 说明联动）。

## 寰宇太阳系（solar_system）v1.0.0：认识太阳系（下午）
- 需求：让学生认识太阳系——恒星/行星/卫星/小行星带的介绍，尽可能真实的 3D 场景，正确轨道 + 自转，并上架商城。
- 结构：新建独立项目 solar-system（React19+TS+Vite8+three.js），沿用 earth-globe 的协议脚手架（gameCode solar_system，postMessage 三件套），纸墨风 UI。
  - src/solarData.ts：BodyData 结构；太阳 + 八大行星 + 冥王星，真实 J2000 轨道根数（aAU/e/周期/倾角/近日点黄经/平近点角/自转小时/轴倾角/颜色/纹理键/简介/facts）；14 颗卫星（月球、火卫一二、木卫一至四等、土卫六、天卫、海卫、冥卫）。displayRadius / moonDisplayRadius / moonOrbitRadius 缩放工具。
  - src/textures.ts：全离线程序化贴图（512×256），fbm 噪声岩石、条带气态（木星大红斑、海王星暗斑）、太阳米粒+黑子、地球海陆冰云、金星、土星环（含卡西尼缝）、径向光晕、双行文字精灵。
  - src/SolarSystem.tsx：开普勒方程牛顿迭代求解（E−e·sinE=M，5 步）→ 真近点角 ν → 含偏心率/近日点黄经/倾角的三维真实轨道；positionAtTime(body, tDays, aDisp)。
  - 比例常数：轨道半径 7.2·a^0.45（压缩外行星）、行星显示半径 0.4·r^0.35（夸大）、太阳 1.75、月球轨道 R*2.5+0.14+i*0.18。
  - 光照 PointLight(0xfff4de,3.1,decay=0) 置于日心 + AmbientLight 0.16 → 自然明暗面；自转用 spinGroup 嵌套 rotation.z=轴倾角，mesh.rotation.y=2π·t/自转天数（逆行取负）。
  - 土星/天王星环 RingGeometry 沿半径重算 UV + 卡西尼缝；小行星带 InstancedMesh 1100 枚（各自 aAU 2.06~3.28/e/倾角/周期/尺寸，逐帧更新矩阵）；柯伊伯带 Points 1200（38~52AU，整体缓转）；星空 Points 3600。
  - 标签精灵逐帧按相机距离缩放保持屏幕恒定大小；Raycaster 拾取（pointerup 位移<6px）→ 档案面板 + 聚焦；跟随模式相机与 controls.target 同步位移。
  - 时间控制：暂停/播放 + 0.2/3/40 预设 + 8 档对数滑杆（0.05~400）+ 回到起点；5 个视角预设（总览/内行星/外行星/俯视/复位）。
  - window.__solarDebug 测试 API：select / setTime / setSpeed / setPlaying / view / readBody / time。
