# 山河三消（shanhe_match3）

省级行政区三要素匹配消消乐：集齐同一省份的【轮廓卡 + 简称卡 + 行政中心卡】三张不同要素牌即可消除，三张相同牌、同省缺牌、跨省混搭均不可消除。

- 关卡 1：8 个高频省区，2–3 层堆叠（课前热身）
- 关卡 2：18 个常见省区（含易混淆），3–4 层堆叠（课中巩固）
- 关卡 3：全部 34 个省级行政区，4–5 层堆叠（会考冲刺）
- 卡槽 6 格，满格无组合即失败；所有布局由构造式算法保证存在通关路径
- **消除即复习（v1.0.0）**：每消除一组弹出记忆卡，把该省的【轮廓 + 简称 + 行政中心】三张
  要素卡 + 省份全名再完整重复一遍；弹窗期间计时暂停，不计入用时
- **提示说清「还差什么」（v1.0.0）**：每局提示 ×3（-5 分/次）。提示会在牌面与卡槽之间播报
  「卡槽里已有【黑龙江省】的轮廓、简称，只差省会，高亮这张点它即可消除」这类具体结论，
  并区分「还差的一张现在就能点」与「还差的一张被压住，要先清障」；卡槽只剩 1 格时附带告警
- **悔棋退回上一张（v1.0.0）**：每局 ×3（-2 分/次）。基于局面快照，把上一手精确还原到点它之前
  ——包括「点下去就凑成三要素并消除」的那一手
- 通关整组 +10 分、过关 +20
- 结束后自动归集薄弱省区到学生本地错题档案（localStorage 永久留存）
- 平台对接：`GAME_READY` / `GAME_INIT(roster)` / `GAME_COMPLETE` / `GAME_SESSION_COMPLETE`

数据来源：`src/data/provinces.json` 轮廓数据与 province-puzzle 同源（2022 省级矢量，Albers 投影）。

## 构建

```powershell
cd shanhe-match3
npm install
npm run build
```

产物：`dist/web/`，随 `manifest.json` 打包为 `shanhe_match3-1.0.1.zip` 上架。
